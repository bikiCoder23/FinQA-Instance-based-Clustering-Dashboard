# FinQA-Instance-based-Clustering-Dashboard
Created a streamlit dashboard to categories the instances in FinQA dataset based on the type of specialized tasks and paradigms, in this case, Numerical QA or Multi-hop QA.

## Dashboard
>The Web Application can be accessed at [FinQA-Instance-based-Clustering-Dashboard.app](https://finapp-instance-based-clustering-dashboard.streamlit.app/)

## Dataset
>Cleveland Clinic Heart Disease Dataset from [🤗 Hugging Face](https://huggingface.co/datasets/ibm-research/finqa)
